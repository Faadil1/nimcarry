# Required Council Response Schema

Every LLM must return the same sections so results can be compared.

1. **Executive diagnosis** — maximum 10 bullets.
2. **What NimCarry is really solving** — current vs stronger formulation.
3. **Hidden problems / jobs** — each labeled EVIDENCE or HYPOTHESIS.
4. **Top opportunities** — no more than 10; explain mechanism, user, and why now.
5. **What to remove / simplify**.
6. **Retention mechanisms**.
7. **Nimiq-native mechanisms** — explain why blockchain/wallet/finality is essential rather than decorative.
8. **Monetization paths** — payer, unit, value, risk.
9. **Visual / interaction opportunities**.
10. **Security / abuse / regulatory risks**.
11. **3 smallest experiments** — one week or less if possible.
12. **Contrarian conclusion** — strongest reason the product may still fail.
13. **Evidence gaps** — what must be learned before committing.
14. **Recommended next 30 days** — sequenced, not a giant feature list.

For every recommendation include:
- user problem;
- evidence or assumption;
- expected behavior change;
- metric;
- implementation complexity: S/M/L;
- reversibility: high/medium/low;
- major risk.
