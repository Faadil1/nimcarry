# Cycle II submission requirements

Verified against the official Cycle II [Rules](https://miniappscompetition.com/rules), [Submit page](https://miniappscompetition.com/submit), [Scoring Guide](https://miniappscompetition.com/scoring), and [FAQ](https://miniappscompetition.com/faq) on 2026-09-12.

## Verified entry requirements

- Participant is 18+; a team may contain up to five people, with one designated representative for communication and prize payout.
- One submission per team per cycle.
- Public GitHub repository linked to the submission.
- Open-source code under the MIT License.
- Built on the Nimiq Pay Mini Apps Framework and meaningfully uses Nimiq Pay/wallet, transaction, or payment infrastructure.
- Supports NIM, USDT, or both; displaying a Nimiq logo alone does not qualify.
- Fully functional and usable on the first try; not merely a prototype or mockup.
- No hardcoded private keys, API secrets, or sensitive credentials.
- Team member name or pseudonym, GitHub profile link, and a Nimiq wallet address for prize payout; the payout wallet is a private portal entry, not a repository field.
- Written Mini App description of no more than 250 words covering what it does, who it is for, and how it uses Nimiq Pay.
- Demo video or walkthrough is optional but encouraged and contributes to storytelling.
- Submission is made through the portal on the Registration Dashboard; the FAQ says the flow signs in with GitHub, accepts the form, and opens a pull request to the official competition repository.

## Current Cycle II timing

Cycle II runs August 24–September 18, according to the Rules and FAQ.

## Scoring categories

- Functionality, reliability and usefulness — 45 points.
- Nimiq Pay and Nimiq integration — 25 points.
- Real usage — 15 points.
- Design and UX — 10 points.
- Builder promotion checklist — 5 points.

The official pages do not expose the authenticated submission form’s complete field-by-field UI in public HTML. Builder-promotion links are prepared separately here but are not represented as a confirmed form field.
