# Internal working notes

These files are the team's working record: handovers, project state, product hypotheses, submission checklists and usage sprints. They are kept public for transparency, but they are not product documentation.

- `HANDOVER.md` and `CANONICAL-STATE.yaml` — current gate, blockers and next actions for contributors
- `product-intelligence/` — hypotheses, experiments, user jobs, monetization and safety notes
- `submission/` — Nimiq Mini Apps Competition (Cycle II) submission material
- `winner-assurance/` — real-usage recruitment plan

Product documentation lives one level up in [`docs/`](../).
