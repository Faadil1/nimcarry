# Experiments

Each experiment gets one file using:

```
# EXP-XXX — Name

## User problem
## Hypothesis
## Evidence / assumption
## Change
## Target population
## Primary metric
## Guardrail metrics
## Safety/privacy check
## Expected result
## Stop condition
## Result
## Decision: PROMOTE / ITERATE / KILL / HOLD
## Follow-up
```
